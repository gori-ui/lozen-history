# Лозен през времето

Production-oriented интерактивен исторически атлас на с. Лозен, София. Картата е централният интерфейс: периоди, времева линия, филтри, търсене, story режим и detail drawer с confidence и директни източници.

## Архитектура

- Vite + React + TypeScript
- Leaflet + OpenStreetMap tiles (без платен API ключ)
- Историческите обекти са в `src/data.ts`, отделени от UI и готови за разширяване
- Приблизителните археологически локализации са `area` зони с визуално различен стил

## Локално стартиране

```bash
npm install
npm run dev
```

Проверки: `npm run lint`, `npm run build`, `npm run test`.

## Методология на източниците

Текущият корпус използва официални и академични публикации: Столична община, Министерство на туризма, Софийска света митрополия и теренни/археологически публикации на РИМ–София. Официалната страница или академичната публикация е посочена директно във всеки обект. `Доказано` означава, че източникът описва обекта/факта; `Вероятно` означава интерпретация или контекст; `Предание` е местна памет, която не е археологически факт.

Калимановата грамота, ранните османски регистри, оброчищата, старите пътища и водениците не са разказани като факти без проверен първичен/академичен цитат. Те са подготвени като слоеве за следваща редакторска итерация. Приписката за поп Добромир Ранчов е отбелязана като предоставена първична снимка; датировката ѝ остава за палеографска проверка.

## Лицензи и deployment

Картографските плочки са от OpenStreetMap и следват attribution изискванията. Не са включени изображения без потвърден лиценз. За production deployment може да се използва всяка статична хостинг платформа с `npm run build` и директория `dist`.
